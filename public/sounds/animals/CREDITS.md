# Animal sound credits

All audio files in this folder are short clips downloaded from
[Wikimedia Commons](https://commons.wikimedia.org/), trimmed to ~3 seconds and
re-encoded as 22.05 kHz mono MP3 (~48 kbps) for the web build.

Each source file is freely licensed (Public Domain, CC0, CC BY, or CC BY-SA).
Original Wikimedia Commons pages are listed below — please open each page for
full author attribution and license details.
